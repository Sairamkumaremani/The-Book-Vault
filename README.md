This is a React-based Bookstore Application that offers a seamless and user-friendly interface for book enthusiasts. 

The application includes the following key features:

1)Browse a Collection of Books: Explore a wide variety of books, categorized for easier navigation.
2)Add to Cart: Select books and add them to your cart for purchase, enhancing the shopping experience.
3)Mark as Favourite: Save books to your favorites list to keep track of your interests and revisit them anytime.

With these features, the application provides an efficient way to manage book purchases and personal preferences.
